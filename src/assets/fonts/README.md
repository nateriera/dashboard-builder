# Bundled fonts

These are the Latin variable WOFF2 subsets served by Google Fonts for Raleway (100–900), Inter (100–900), and JetBrains Mono (100–800). Their respective OFL licenses are included in this directory.

- https://github.com/google/fonts/tree/main/ofl/raleway
- https://github.com/google/fonts/tree/main/ofl/inter
- https://github.com/google/fonts/tree/main/ofl/jetbrainsmono
